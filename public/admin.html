X integration

OAuth, publishing and media behavior.

# X setup
X_CLIENT_ID
X_CLIENT_SECRET
X_REDIRECT_URI=https://creovah.onrender.com/api/connections/x/callback

Scopes: tweet.read tweet.write users.read media.write offline.access

OAuth 2.0 Authorization Code + PKCE. Images up to 4; one video. Published X posts can be edited within X's edit window.

TikTok publishing

Login Kit + Content Posting API notes.

# TikTok setup
TIKTOK_CLIENT_KEY
TIKTOK_CLIENT_SECRET
TIKTOK_REDIRECT_URI=https://creovah.onrender.com/api/connections/tiktok/callback

Scopes: user.info.basic, video.publish

Direct posting accepts video and TikTok scheduling is intentionally blocked in this build.
